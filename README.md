# System 2 Manufacturing · website demo

The page about System 2 Manufacturing (`index.html`) and the program to try (`app.html`), built as
static files. The demo runs entirely in the visitor's browser on made-up data (the metal workshop
Talleres Norte); nothing is sent anywhere and nothing is kept.

These are built files, published with GitHub Pages. They are produced by `npm run package:demo` in
the System 2 Manufacturing project.
